AI CTF Intelligence

Laboratorium CTF butuh server, bukan GitHub Pages.

Halaman portofolio dipublikasikan di GitHub Pages sebagai situs statis. AI CTF Intelligence adalah aplikasi penuh: memakai API, autentikasi berbasis cookie, WebSocket untuk terminal, PostgreSQL, dan kontainer Docker untuk sandbox. GitHub Pages hanya menyajikan HTML/CSS/JS, sehingga fitur-fitur itu tidak bisa berjalan di sini.

Status di alamat ini: informasi akses. Untuk membuka laboratorium lengkap, jalankan aplikasi di server/VPS atau di lokal dengan npm start, lalu buka http://localhost:3000/ctf/login.
