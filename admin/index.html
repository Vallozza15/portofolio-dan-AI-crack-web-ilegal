Manajemen konten privat

Arsip tetap milik Anda. Tanpa jalan pintas.

Studio ini belum terhubung ke backend, jadi belum dapat mengautentikasi siapa pun atau mengunggah gambar. Portofolio publik tetap memakai gambar contoh yang diberi label jelas. Selesaikan penyiapan di bawah untuk mengaktifkan autentikasi dan penyimpanan Supabase yang sebenarnya.

01

Buat proyek Supabase

Jalankan supabase/schema.sql di editor SQL. Skrip ini membuat tabel galeri, fungsi peran admin, bucket penyimpanan, dan kebijakan keamanan tingkat baris.

02

Tambahkan variabel lingkungan publik

Isi NEXT_PUBLIC_SUPABASE_URL dan NEXT_PUBLIC_SUPABASE_ANON_KEY di .env.local. Gunakan hanya anon key — jangan pernah membuka service-role key ke peramban.

03

Buat akun admin Anda

Tambahkan pengguna di Supabase Authentication, lalu masukkan UUID pengguna itu ke public.admin_users. Nonaktifkan pendaftaran publik untuk studio satu pemilik.

04

Mulai ulang lalu masuk

Formulir masuk hanya muncul saat proyek Supabase asli sudah dikonfigurasi. Tidak ada autentikasi palsu atau bypass kata sandi di sisi klien.

Variabel lingkungan

NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
